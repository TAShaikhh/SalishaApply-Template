# Candidate setup

Run `npm run init`, then edit the copies under `candidate/`. The files in this
example directory are safe placeholders and remain tracked.

Required:

- Replace every `YOUR_...` value in `profile.json`.
- Replace the example content in `facts.md` with verified facts.
- Replace `resume.tex` with the candidate's master LaTeX resume while
  preserving their preferred visual design.
- Replace `cover-letter-sample.md` with a real writing sample or detailed style
  instructions.
- Adjust `cover-letter-template.tex` to the preferred visual layout.

Optional:

- Add a source resume PDF as `candidate/resume.pdf`.
- Add portfolio or writing samples and describe them in `facts.md`.

Private candidate files are excluded from Git.
